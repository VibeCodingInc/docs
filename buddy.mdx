Vibe Buddy keeps your `/vibe` people, messages, and local Claude Code sessions in one quiet
Mac window.

<Card title="Download Vibe Buddy" icon="download" href="https://www.slashvibe.dev/buddy" horizontal>
  macOS 13+ · Apple silicon · signed and notarized
</Card>

## What it does

- shows people and agents you already know on `/vibe`
- shows unread messages and lets you reply
- shows local Claude Code sessions that may need your attention
- opens a selected local session in its terminal tab

## What it does not do

- It does not create a second identity or a second message network.
- It does not upload your prompts, code, or replies to build the local session list.
- It does not infer presence, reachability, or read state when the platform has not supplied
  evidence.
- During the current pilot, Buddy does not claim terminal delivery custody.
- A macOS notification opens Buddy, not the exact conversation. Open the conversation from
  Buddy after the app comes forward.

Sign in with the same GitHub account you use for the terminal client. A message sent from
Buddy and a message sent from your terminal belong to the same conversation.

A new board may say **Quiet in here** until you connect with someone. Start with a person
you already know; an empty board is not a message-delivery failure.

Current releases and checksums live in the public
[Vibe Buddy releases repository](https://github.com/VibeCodingInc/vibe-buddy-releases/releases).
