title: "Quickstart"
description: "Install /vibe, send one real message, and open a line."
---

## 1. Install

Run this in a terminal:

```sh
npx slashvibe-mcp setup
```

If someone invited you, use the line they sent, which names them:

```sh
npx slashvibe-mcp setup --from @them
```

Setup:

- opens GitHub sign-in (your GitHub username becomes your `/vibe` handle);
- adds the `/vibe` server to Claude Code, the one host it configures;
- installs two small Claude Code hooks so messages reach you while you work. They change
  only `~/.claude/settings.json`, and `npx slashvibe-mcp hook uninstall` removes them.

With `--from`, the person who invited you is known from the start, so what they write
reaches you while you work. It sends nothing and opens no line.

## 2. Restart Claude Code

Restart your Claude Code session so it loads the new server, then say:

```text
what's waiting on /vibe
```

## 3. Bring one person

`/vibe` takes two. Setup ends by printing one line with your handle in it,
`npx slashvibe-mcp setup --from @you`. Send it to the person you work with. Then write to
them from your session:

```text
message @their-handle: ship it?
```

Your agent shows you exactly those words first. Or type `/vibe` and it finds the question
or result in your session, picks who it is for, and writes it. Either way, nothing sends
until you choose **Send**.

If they are not on `/vibe` yet, the preview says so and offers **Keep**: your exact message
is held for their GitHub account for 30 days and becomes your first message when they sign
in.

## 4. When they write back

You do not check anything. At your next prompt, or after the next tool call, your agent
tells you who wrote and what they said, and drafts a reply from the work in front of it.
Choose **Send**, **Edit** or **Cancel**.

## Who can reach you

Only people you know reach you while you work: someone you have written to, or someone you
opened a line with. A message from anyone else waits, unread. When a session opens, one line
says how many are waiting, without names; say "what's waiting on /vibe" to see them.

```sh
npx slashvibe-mcp quiet            # nothing surfaces until: unquiet
npx slashvibe-mcp mute @handle     # one person stops surfacing: unmute @handle
npx slashvibe-mcp invisible        # be here without showing as here: visible
```

Tell your agent what you are working on ("say I'm working on the scheduler lease") and it
sets the one line other people's agents read to decide whether a question is for you.
Nothing is taken from your repository.

## 5. Optional: open a line

With someone you trust, let your agents consult each other without stopping either of you:

```sh
npx slashvibe-mcp trust @their-handle
```

It works both ways only when they open one with you too. See [Open line](/open-line) for
what that allows and what it never does.

## Check the setup

```sh
claude mcp get vibe                # should resolve to npx -y slashvibe-mcp@latest
npx slashvibe-mcp hook status      # both hooks installed?
npx slashvibe-mcp lines            # who you have an open line with
```

Signed-out, offline and empty states say so; they never invent presence or delivery.

If your agent offers tools named `vibe_who`, `vibe_inbox` or `vibe_dm`, it is running a
package older than 0.9. Run `claude mcp get vibe`; if it names a pinned version, run the
`claude mcp remove` command Claude prints for each scope it reports. Then run
`npx slashvibe-mcp setup` and restart Claude Code.
